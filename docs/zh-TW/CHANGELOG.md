# 更新紀錄

## V0.7.0 — 2026-11-26

- 引入赤壁主題原創場景與孫劉雙旗，保留彩色人物棋子及木質棋盤。
- 重構主視窗：頂部語言、設定與關於入口，棋盤旁紅金選取牌及獨立解題輔助卡片。
- 將復原與暫停並排，獨立顯示推薦棋子和清除提示按鈕，玩法說明支援摺疊。
- 新增設定視窗，可調整背景壓暗程度、動畫速度及介面語言；設定自動儲存。
- 新增關於視窗，顯示版本、開源授權與專案連結。
- 改善三語版面與視窗尺寸適配，保留原有規則、移動與成績邏輯。

## V0.6.0 — 2026-11-26

- 新增「下一步提示」，使用現有最短單格路徑求解器推薦一次合法移動，不自動操作棋子。
- 以金色邊框標記推薦棋子，在底部提示中說明棋子、格位與移動方向；保留原有綠色目標預選框。
- 支援手動清除提示；移動、復原造成棋局變化、暫停或重開後自動清除過期提示。
- 支援簡體中文、繁體中文與英文提示，切換語言時保留棋局與步數。
- 新增提示合法性、棋局狀態、三語顯示與視窗配置回歸測試。

## V0.5.0 — 2026-11-26

- 修正棋子滑動動畫期間實際顯示位置與滑鼠命中區域不一致的問題，統一幾何計算並保留棋子邊緣點選容差（PR #5）。
- 完善動畫期間視覺與邏輯空位的雙重判定，避免放開滑鼠時誤觸發移動。
- 修正快速復原並再次通關時通關提示可能重複觸發的問題，待動畫結束後顯示提示，並在復原、重開及關閉視窗時取消過期通知。
- 修正棋盤鍵盤焦點無法正常離開的問題，使用 Q / E 切換棋子，Tab / Shift+Tab 切換介面焦點，保留方向鍵 / WASD 移動。
- 新增通關通知、動畫速度、連續拖曳、多選、復原及鍵盤焦點導覽回歸測試。

## V0.4.0 — 2026-11-25

- 修正英文介面在較小視窗下右側面板橫向溢出的問題，改善三語說明文字換行與側欄寬度調整。
- 在視窗右上角新增語言切換按鈕，可於簡體中文、繁體中文及 English 之間即時切換。
- 棋盤文字、武將姓名、按鈕、成績、計時、操作提示、滑動速度及確認對話框均支援三語介面。
- 語言選項會獨立儲存，重新啟動後沿用；切換語言不會重設棋局、復原紀錄、計時或動畫速度。
- 保留完整棋子目標提示和自動調整視窗版面，並改善較長英文人名的姓名牌顯示。
- 增加翻譯內容完整性、格式參數一致性、偏好儲存與視窗尺寸回歸測試。
- 合併同方向重疊的移動預選框，統一描邊與填色，保留各合法移動距離。
- Windows 發行改用單一 EXE 檔，ZIP 僅包含程式、README.md 與合併授權聲明 LICENSE.txt。

## V0.3.0 — 2026-11-21

- 改善快速連續移動時的動畫銜接，從目前顯示位置滑動，避免從舊格位重新開始。
- 復原單枚與群組棋子移動時使用平滑返回動畫，連續操作保持畫面連貫。
- 新增慢、標準、快三段滑動速度，從右側操作區調整並自動儲存。
- 在 Windows 本機建置及 GitHub Actions 中統計 EXE、程式目錄與發布 ZIP 的實際容量。
- 改善 GitHub Release 自動發行：保留 Windows 建置附件；既有同版本 Release 改為更新附件。
- 新增動畫銜接、復原、速度設定及容量統計回歸測試。

## V0.2.0 — 2026-11-20

- 改善右側玩法提示排版：依操作類型分組、自動換行，空間不足時可在提示框內捲動閱讀，避免末尾文字遭到裁切。

- 點選人物後再點選合法的目標空位，即可沿直線移動；不能穿越障礙。
- Ctrl+點選可多選人物，並可透過滑鼠拖曳、點選目標空位或方向鍵進行同向同步移動。
- 群組移動須方向與距離一致，整組檢查邊界及碰撞；步數依棋子數量與位移格數計算，一組動作可一次復原。
- 目標區域依棋子完整占位繪製：曹操為單一 2×2 正方形、橫向武將為 2×1 長方形、直向武將為 1×2 長方形、小兵為 1×1 正方形。
- 滑鼠移動成功後自動清除選取與綠色提示；無效移動保留提示；鍵盤移動保留選取但隱藏綠色提示。
- 新增同步移動、目標幾何與 Qt 互動測試。

## V0.1.0 — 2026-11-04

- 實作經典「橫刀立馬」4×5 棋局、邊界與碰撞判定，以及過關條件。
- 加入彩色三國人物插畫、木質棋盤及羊皮紙風格的操作區。
- 支援單枚棋子滑鼠拖曳（合法直線可連續移動多格）、方向鍵 / WASD、復原、重新開始與暫停。
- 首次有效移動開始計時；每枚棋子每移動一格計一步；過關後儲存本機最佳成績。
- 包含規則、模型、紀錄、資源及 GUI 基本測試，以及 Windows 建置腳本。
