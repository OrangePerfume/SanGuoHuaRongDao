# 三國華容道 v0.6.0

新增依目前棋局計算的下一步提示，協助玩家自主解題。

## 本次更新 · 2026-11-26

- 新增「下一步提示」，使用現有最短單格路徑求解器推薦一次合法移動，不自動操作棋子。
- 以金色邊框標記推薦棋子，在底部提示中說明棋子、格位與移動方向；保留原有綠色目標預選框。
- 支援手動清除提示；移動、復原造成棋局變化、暫停或重開後自動清除過期提示。
- 支援簡體中文、繁體中文與英文提示，切換語言時保留棋局與步數。
- 新增提示合法性、棋局狀態、三語顯示與視窗配置回歸測試。

## 下載與執行

Windows x64 附件：`SanGuoHuaRongDao-v0.6.0-win-x64.zip`。完整解壓縮並執行 `SanGuoHuaRongDao.exe`。
