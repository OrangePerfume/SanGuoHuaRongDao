# 三國華容道 v0.4.0

新增遊戲介面三語切換，可直接選擇簡體中文、繁體中文或英文，無須重新啟動。

## 本次更新 · 2026-11-25

- 於視窗右上角新增語言切換按鈕，所選語言即時套用並儲存。
- 完整翻譯棋盤與武將姓名、操作按鈕、狀態與成績、玩法提示及遊戲對話框。
- 切換時保留目前棋局、計時、步數、復原紀錄、動畫速度及綠色目標提示狀態。
- 改善較長英文人物姓名在棋子姓名牌上的顯示。
- 擴充三語翻譯完整性、設定儲存及介面互動回歸測試。
- 合併同方向重疊的移動預選框，統一描邊與填色，保留各合法移動距離。
- Windows 發行改用單一 EXE 檔，ZIP 僅包含程式、README.md 與合併授權聲明 LICENSE.txt。

## 下載與執行

Windows x64 附件：`SanGuoHuaRongDao-v0.4.0-win-x64.zip`。完整解壓縮後執行 `SanGuoHuaRongDao.exe`。
