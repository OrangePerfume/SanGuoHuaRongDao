# V0.10.0 · 限時與步數挑戰

## V0.10.0 — 2026-11-27

- 新增獨立挑戰模式入口，支援六種經典棋局的限時挑戰與步數挑戰。
- 提供入門、進階、高手、極限四級難度，依據棋局最短單格移動數設定時間或步數限制。
- 限時從介面準備完成後立即倒數，禁止暫停、復原及解題提示；每枚棋子每格計一步，多選亦受步數限制。
- 達到時限即失敗，步數耗盡且尚未通關即失敗；恰好用完步數通關有效。
- 挑戰結束顯示結果與獨立最佳成績；限時以用時優先，步數以步數優先，同分比較另一項指標。
- 挑戰成績依棋局、模式及難度分開儲存，採用原子寫入、嚴格資料驗證及既有單一寫入者鎖；異常成績保留原始檔案並支援重試。
- 挑戰不儲存進行中的進度，不影響經典模式存檔、復原紀錄及個人統計；返回經典模式可繼續原棋局。
- 同步三語挑戰介面及提示，擴充規則、紀錄隔離、邊界條件、GUI 及 EXE 自我檢查。保留既有安全與品質檢查機制。
- 新增挑戰進度卡片、剩餘量預警及獨立結算視窗；使用固定結算快照，支援再次挑戰及返回經典模式。
- 新增全部 48 種挑戰組合的成績總覽，區分未完成與讀取異常。
- 保護進入挑戰前的經典存檔，支援儲存失敗重試與取消；唯讀挑戰事先確認，損毀成績經確認後獨立備份。
- 完成介面準備後開始計時，限制多選移動預覽，區分成績讀寫錯誤。
