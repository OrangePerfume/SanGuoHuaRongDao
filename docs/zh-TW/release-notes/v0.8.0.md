# V0.8.0 · 經典棋局擴充

## V0.8.0 — 2026-11-27

- 新增六種經典一橫佈局及頂部棋局選擇選單。
- 顯示按單格計步規則驗證的最短路徑步數。
- 切換棋局前確認放棄目前進度，清除計時、復原、選取與提示狀態；重開保留目前棋局。
- 依棋局獨立儲存最佳紀錄，相容原橫刀立馬紀錄。
- 同步三語棋局名稱、提示及選單，新增佈局可解性與切換回歸測試。
