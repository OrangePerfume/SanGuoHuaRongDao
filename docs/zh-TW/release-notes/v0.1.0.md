# 三國華容道 v0.1.0

Windows 單機華容道的首個公開功能版本，保留經典「橫刀立馬」規則與彩色木質人物棋盤。

## 此版本功能

## V0.1.0 — 2026-11-04

- 實作經典「橫刀立馬」4×5 棋局、邊界與碰撞判定，以及過關條件。
- 加入彩色三國人物插畫、木質棋盤及羊皮紙風格的操作區。
- 支援單枚棋子滑鼠拖曳（合法直線可連續移動多格）、方向鍵 / WASD、復原、重新開始與暫停。
- 首次有效移動開始計時；每枚棋子每移動一格計一步；過關後儲存本機最佳成績。
- 包含規則、模型、紀錄、資源及 GUI 基本測試，以及 Windows 建置腳本。

## 下載與驗證

GitHub Actions 通過測試並完成建置後，下載 `SanGuoHuaRongDao-v0.1.0-win-x64.zip`，完整解壓縮後執行 `SanGuoHuaRongDao/SanGuoHuaRongDao.exe`。不要只複製 EXE。

> 應在 Windows 測試及建置成功後才建立發行標籤與 Release。本文件不代表已實際發行或完成所有螢幕設定的驗收。
