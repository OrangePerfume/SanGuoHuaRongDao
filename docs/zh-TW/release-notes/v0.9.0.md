# V0.9.0 · 遊戲存檔與個人成績

## V0.9.0 — 2026-11-27

- 新增具版本資訊的本機自動存檔，還原目前棋局、步數、計時、復原紀錄及輔助使用次數；還原未完成的棋局時暫停，離線時間不計入用時。
- 新增個人成績視窗，彙整各棋局歷史最佳成績及累計通關、無輔助通關、無輔助最短步數通關、移動、復原及提示次數。
- 為未來挑戰與成就系統預留統計架構，避免同一局復原後再次通關重複計數，保留舊版最佳紀錄。
- 採用原子寫入、檔案鎖、檔案大小與歷史長度限制、棋局及移動紀錄逐步驗證；異常或不相容存檔保留原始檔案。
- 引入 CodeQL 安全掃描、Ruff 靜態品質檢查、相依套件漏洞稽核及相依套件一致性檢查；嚴格測試、EXE 自我檢查與壓縮檔檢查通過後方可發行。
- 分離建置及發行權限，鎖定發行原始碼提交，強化本機成績檔案驗證並擴充存檔與統計回歸測試。
- 新增儲存失敗離開保護、損毀存檔備份與重建、手動備份及資料目錄入口；唯讀視窗顯示已儲存成績而不累計操作。
- 將最佳成績與統計原子提交，相容舊成績檔案並自動重試同步；略過未變更的重複存檔。
- 優化個人成績總覽與棋局紀錄，新增最快通關、累計通關用時、最短步數差距及刷新最佳成績提示。
- 升級並鎖定 Pillow 13.0.0，修正已知相依套件安全漏洞。
