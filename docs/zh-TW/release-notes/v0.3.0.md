# 三國華容道 v0.3.0

改善棋子連續移動與復原時的動畫銜接，新增滑動速度設定，並完善 Windows 建置與發行流程。

## 版本更新 · 2026-11-21

- 改善快速連續移動時的動畫銜接，從目前顯示位置滑動，避免從舊格位重新開始。
- 復原單枚與群組棋子移動時使用平滑返回動畫，連續操作保持畫面連貫。
- 新增慢、標準、快三段滑動速度，從右側操作區調整並自動儲存。
- 在 Windows 本機建置及 GitHub Actions 中統計 EXE、程式目錄與發布 ZIP 的實際容量。
- 改善 GitHub Release 自動發行：保留 Windows 建置附件；既有同版本 Release 改為更新附件。
- 新增動畫銜接、復原、速度設定及容量統計回歸測試。

## 下載與執行

發布檔案為 `SanGuoHuaRongDao-v0.3.0-win-x64.zip`。完整解壓縮後執行 `SanGuoHuaRongDao/SanGuoHuaRongDao.exe`，並保留資料夾中的相依檔案。
