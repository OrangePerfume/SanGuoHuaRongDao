# 三國華容道 v0.2.0

在初版經典華容道上新增點選目的地移動、Ctrl 多選，以及依棋子完整形狀呈現的移動提示。

## 此版本功能

## V0.2.0 — 2026-11-20

- 改善右側玩法提示排版：分組說明、自動換行，空間不足時可捲動閱讀，避免文字裁切。

- 點選人物後再點選合法的目標空位，即可沿直線移動；不能穿越障礙。
- Ctrl+點選可多選人物，並可透過滑鼠拖曳、點選目標空位或方向鍵進行同向同步移動。
- 群組移動須方向與距離一致，整組檢查邊界及碰撞；步數依棋子數量與位移格數計算，一組動作可一次復原。
- 目標區域依棋子完整占位繪製：曹操為單一 2×2 正方形、橫向武將為 2×1 長方形、直向武將為 1×2 長方形、小兵為 1×1 正方形。
- 滑鼠移動成功後自動清除選取與綠色提示；無效移動保留提示；鍵盤移動保留選取但隱藏綠色提示。
- 新增同步移動、目標幾何與 Qt 互動測試。

## 下載與驗證

GitHub Actions 通過測試並完成建置後，下載 `SanGuoHuaRongDao-v0.2.0-win-x64.zip`，完整解壓縮後執行 `SanGuoHuaRongDao/SanGuoHuaRongDao.exe`。不要只複製 EXE。

> 應在 Windows 測試及建置成功後才建立發行標籤與 Release。本文件不代表已實際發行或完成所有螢幕設定的驗收。
