# V0.7.0 · 赤壁主題與現代化介面

新增赤壁主題背景、紅金選取牌與現代化操作面板。

## V0.7.0 — 2026-11-26

- 引入赤壁主題原創場景與孫劉雙旗，保留彩色人物棋子及木質棋盤。
- 重構主視窗：頂部語言、設定與關於入口，棋盤旁紅金選取牌及獨立解題輔助卡片。
- 將復原與暫停並排，獨立顯示推薦棋子和清除提示按鈕，玩法說明支援摺疊。
- 新增設定視窗，可調整背景壓暗程度、動畫速度及介面語言；設定自動儲存。
- 新增關於視窗，顯示版本、開源授權與專案連結。
- 改善三語版面與視窗尺寸適配，保留原有規則、移動與成績邏輯。
