# Three Kingdoms Klotski v0.4.0

Added instant in-game language switching between Simplified Chinese, Traditional Chinese, and English, without restarting the game.

## Changes · 2026-11-25

- Fixed horizontal overflow in the English sidebar at smaller window sizes and improved wrapping and sidebar width adaptation across all three languages.
- Added an upper-right language button with immediate switching and saved preferences.
- Localized the board, character names, controls, statuses, records, help text, and game dialogs.
- Preserved puzzle state, timer, moves, undo history, speed settings, and green hints when changing language.
- Improved piece-name labels for longer English character names.
- Added regression checks for localization coverage, persistence, and UI behavior.
- Merged overlapping destination outlines in the same direction into one uniformly filled rectangle while preserving legal movement distances.
- Switched Windows distribution to a single-file EXE with a ZIP containing only the executable, README.md and combined LICENSE.txt.

## Download and run

Windows x64 archive: `SanGuoHuaRongDao-v0.4.0-win-x64.zip`. Extract the whole archive and start `SanGuoHuaRongDao.exe`.
