# Three Kingdoms Klotski v0.1.0

The initial feature release of the classic *Heng Dao Li Ma* Windows sliding-block puzzle with colorful character tiles and a wooden board.

## Changes

## V0.1.0 — 2026-11-04

- Implemented the classic 4×5 *Heng Dao Li Ma* puzzle, collision and boundary checks, and the win condition.
- Added painted Three Kingdoms characters, a wooden board, and parchment-themed controls.
- Supported single-piece drag movement (including legal multi-cell straight moves), arrow/WASD keys, undo, restart, and pause.
- Started the timer on the first valid move, counted one step per piece per cell, and stored local best scores after a win.
- Included rules, session, record, asset, and basic GUI tests, along with the Windows build script.

## Download and verification

After the GitHub Actions tests and build succeed, download `SanGuoHuaRongDao-v0.1.0-win-x64.zip`, fully extract the directory, then run `SanGuoHuaRongDao/SanGuoHuaRongDao.exe`. Do not copy only the EXE.

> Create the release tag and Release only after Windows tests and builds succeed. This document is not proof that publication or every display-configuration test has completed.
